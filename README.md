# aSoD_Simulator
Autonomous Shuttle on Demand (aSoD) Simulation Framework

## Overview

The aSoD_Simulator is a framework designed to simulate autonomous shuttle services on demand. It aims to model and analyze the behavior of autonomous shuttles in urban environments, focusing on traffic dynamics, passenger demand, and operational efficiency.

**Note:** This project is a work in progress. Features and functionality are actively being developed and refined.

## Input

The simulator takes the following inputs:
- **Road Network Data:** Provided in formats such as OSM or CSV, describing nodes, edges, and traffic attributes.
- **Passenger Requests:** Includes pickup and drop-off locations, timestamps, and demand patterns.
- **Traffic Parameters:** Configurations such as vehicle speeds, lane capacities, and routing algorithms.

## Output

The simulator generates:
- **Traffic Simulation Results:** Includes vehicle trajectories, travel times, and congestion metrics.
- **Passenger Metrics:** Such as wait times, travel times, and service coverage.
- **Visualization:** Graphical representations of road networks, traffic flows, and shuttle movements.

This project is under active development. Contributions and feedback are welcome as we continue to enhance the framework's capabilities.
